01產品是什麼(分析摘要)

一句話:以「證據」為本的 SEO / AEO / GEO 檢測器 — 找出阻止搜尋引擎與 AI 答案引擎發現、理解、引用你網站的原因,並給出優先修復計畫。

SEOHTTP、robots、索引指令、canonical、sitemap、初始 HTML、結構化資料
AEO答案摘要、章節結構、定義、來源、作者、日期、agent 可操作語意
GEOAI crawler 存取、可引用證據、品牌實體、摘要控制、server 渲染

運作流程

  1. 使用者提交網址 → POST /api/audits 正規化網址、原子配額、入列持久任務(pg-boss)
  2. 獨立 worker 以 headless Chromium 抓取原始+渲染 HTML,執行版本化規則引擎的全部檢查
  3. 公開結果頁(動畫)免費呈現摘要 findings;輪詢自動退避
  4. Email gate → HubSpot 同步 → 7 天雜湊 token 開啟 /report/[token] 完整報告
  5. LLM(OpenRouter,預設關閉)只負責敘事,永不決定 pass/fail、不接觸名單資料

技術架構

Next.js(App Router, TS)+ PostgreSQL + pg-boss + Playwright/Chromium worker + Docker Compose + Caddy(HTTPS)。具備健康檢查端點、任務重試退避、備份還原文件、vitest 測試。是生產級產品,不是 demo。

商業定位:為 geo.tenten.co 產生合格名單 — 用可信診斷換 email,高意圖名單進 HubSpot 流程。評審視角:真實問題、真實商模、完整產品體驗(Potential Impact + Design 得分點)。
